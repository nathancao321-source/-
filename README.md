# THE LAST ARK · 三 Agent 四小时协作包

本包回答本轮的请求：**接口协议、分工、四小时时间计划和可以直接复制的 Agent 任务书**。参考提示词里的仓库创建和完整开发要求，留给实施阶段的 Agent 3 执行；本包本身不是已经完成的游戏。

优先级以本轮明确要求为准：**视觉 > 剧情 > 玩法复杂度**。可运行、可通关、控制正确仍是验收底线。建议交付一张地图、三个连续视觉区域、一个可选发现点和七句短叙事。3–5 分钟首次体验是调参目标，不是已测时长。

## 阅读顺序

1. `01-接口协议.md`：边界、数据流、生命周期和交接规则。
2. `02-四小时时间计划.md`：从团队确认开始计时的相对时间表、里程碑和删减方案。
3. `03-Agent任务书.md`：分别交给策划、视觉、核心开发。
4. `contracts.ts`：拟冻结的 TypeScript 共享接口 v1。
5. `level.draft.ts`：带数值的完整关卡草案，**未经过物理可通关测试**。
6. `render.fixture.ts`：视觉开发假数据工厂，方便视觉 Agent 不等物理完成就开工。

实施开始后，由 Agent 3 将接口放入 `src/shared/contracts.ts`；Agent 1 将关卡迁入 `src/content/level01.ts`，修改导入路径。本目录保留为交接快照，运行时只以 `src/shared/contracts.ts` 为接口真源，禁止维护两套运行时类型。
