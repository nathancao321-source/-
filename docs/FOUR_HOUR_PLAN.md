# 四小时并行开发时间计划

四小时为墙钟上限，三个 agent 并行；不是每人轮流四小时。T+00 从实际启动实现冲刺起算。本轮先交付协议及分工文档，尚未宣称完成游戏、npm 验收或 GitHub 发布。

## 0—15 分钟：统一坐标、接口、范围

- 策划：给出一关地图草案、两句开场/结尾和预期三段护航路线。
- 视觉：确定 1200×720 构图、七种对象识别与颜色，准备三个 mock 快照画面。
- 开发：初始化 Vite/TS，装依赖，配置 dev/build/test/typecheck，验证 GitHub 登录、创建公开仓库权限和 Git 作者信息。
- 主 agent：冻结 contracts.ts v0.1；确认输入、时间步、状态与入港语义。
- 门槛：三方导入同一类型；任何 GitHub 权限问题在此时公开记录，不拖到最后。

## 15—45 分钟：独立产出可拼接模块

- 策划：产出纯数据 LevelSpec，中央危险星体、方舟初速、目标港和一颗可受力陨石；标明候选参数未经验证。
- 视觉：createRenderer 可绘制几何地图、两种力场、速度/状态/操作提示；基础配色、留白与世界等比缩放同时完成。
- 开发：向量/力场、所有动态体统一积分、InputAdapter、状态机和测试 harness。
- 门槛：45 分钟三个约定导出都存在；不得各自搭一份完整游戏。

## 45—90 分钟：第一次完整集成

- 45—60 分钟：开发接入真实关卡、真实输入与渲染，npm run dev 首次可操作；策划检查坐标/路线；视觉检查比例/颜色/场半径。
- 60—90 分钟：补齐失败、速度限制入港、暂停、重试与失焦；用真实快照替换 mock。
- 门槛：90 分钟必须可以发射、双人操作、失败和重试。若失败，暂停所有额外视觉装饰与叙事，三方只处理集成故障。

## 90—150 分钟：证明地图可通关

- 策划 + 开发：记录不干预会失败的基线，以及一个只包含合法输入的双人成功回放；调大安全走廊、减小初速或提高港口容错，以降低时机要求。
- 视觉：在稳定接口上完善基础画面层次与提示，力场开关、危险边界、超速警告必须读得清。
- 开发：加入方向叠加、陨石受力、玩家免疫、暂停不漂移、重试等自动测试；检查连续碰撞、数值稳定。
- 门槛：150 分钟有确定性的成功输入回放及不干预失败证据，且两个玩家的力场都确实发挥作用。不存在成功证据时，禁止继续第二关/黑洞/额外画面。

## 150—180 分钟：视觉与叙事集中完善

- 视觉：打磨基础 Canvas 构图、可辨识星体轮廓、空间港和操作反馈；可选择增加轻量确定性背景星点，但不做粒子系统/复杂动画。
- 策划：开场、绕障、抵港形成简单探索节奏，文案总量控制在约 150 中文字内；不加长对话和剧情树。
- 开发：浏览器实际键盘流程、缩放、刷新、长时间模拟和构建测试，修复集成缺陷。
- 门槛：180 分钟功能冻结；不增加第二关、新物体体系和新依赖。

## 180—210 分钟：验收与修复

- 三方按 README 验收清单走一遍；测试方向、叠加、同键盘并发、失焦、失败、胜利、重试、数值稳定。
- 开发：npm install、npm run dev、npm run build、npm test、typecheck 全部记录实际结果；安装时采用 lockfile 复现，可补 npm ci。
- 策划：确认通关回放不是直接改状态的作弊测试，失败基线也可复现；记录人工双人测试缺口。
- 视觉：确认正常、危险、低速入港三场景真实可读；显示性能只能报告实测机器数据。
- 门槛：210 分钟代码冻结，剩余时间仅处理发布阻塞/严重缺陷。

## 210—240 分钟：发布缓冲

- 完善中文 README：背景、玩法、按键、启动、结构、已实现/未实现、真实测试记录与视觉扩展点；添加 MIT License。
- 核验暂存区不含 node_modules、dist、token、个人文件；Agent 3 commit/push，检查远端默认分支与 commit。
- 确认仓库公开属性后给出 GitHub URL、启动步骤和测试结果；保留实际失败或未验证项。
- 门槛：成功发布，或具体说明认证/权限阻碍与本地已完成内容；不得伪造链接或测试结论。

## 超时降级顺序

第二关 → 黑洞/额外星体种类 → 装饰背景和高级 HUD → 剧情触发扩展。始终保留一关、两名玩家、吸引与排斥、至少一颗可受力陨石、一个引力危险体、完整胜负、暂停/重试、力场半径提示与自动测试。

若 120 分钟尚无初步可通关路线，先扩大绕障空间与港口、降低初速和中央星体强度；不要靠精确到单帧的操作救关卡。若 180 分钟仍有稳定性故障，只修核心，不扩展表现。

## 发布验收的硬门槛

1. 从干净安装可启动，build 与自动测试成功，页面无运行错误。
2. 两人同时移动/施力，斜向归一化，Space/R 不连发；浏览器不滚动，失焦后无粘键。
3. 吸引/排斥方向、矢量叠加正确；技能同时作用方舟和陨石，玩家不受引力。
4. 无干预不会安全抵港；合法双人回放可绕障减速获胜；高于阈值不得提前获胜。
5. 碰撞/吞噬（若实现）/越界准确失败；暂停冻结、恢复无补时跳跃；重试恢复位置速度状态。
6. 近零距离、长时间运行、大帧间隔和高速度不会产生 NaN、Infinity 或穿透明显障碍。
7. 渲染仅消费快照，替换 renderer 不改模拟逻辑；所有状态能显示。
8. README 如实区分自动化、浏览器验证、真实双人键盘试玩；GitHub 发布状态可核实。
